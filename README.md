# Shaxsiy Portfolio Loyiham

Ushbu Loyiha mening shaxsiy portfolioyim bo'lib, unda men haqimdagi ma'lumotlar, bilimlarim va qiziqishlarim jamlangan!

## Ishlatilgan Texnologiyalar

- **HTML5:** Sahifa strukturasi va semantik teglardan foydalanildi.
- **CSS3:**
  - Responsive dizayn uchun Media Queries (768px, 1024px, 1200px)
  - Sticky Header va Fixed "Yuqoriga qaytish" tugmasi
  - Pseudo-klasslar (:hover, :focus-visible, :disabled, :nth-child)
  - Pseudo-elementlar (::after yordamida chiziq animatsiyasi)
- **JavaScript:** Belgilar sanagichi funksionalligi.
- **Git & GitHub:** Versiyalarni boshqarish va loyihani joylashtirish.

## Loyiha Tuzilishi

- **assets/images/** — Loyihaning asosiy fayllari joylashgan papka:
  - `index.html` — Bosh sahifa
  - `about.html` — Men haqimda sahifasi
  - `contact.html` — Bog'lanish sahifasi
  - `style.css` — Asosiy CSS stillari va media queries
  - `script.js` — JavaScript mantiqiy kodlari
  - `README.md` — Loyiha haqida hujjatlashtirish
